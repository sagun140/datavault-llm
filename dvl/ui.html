Generation selects and orders attested bindings. It never rebinds a pattern to different fillers — that would read fluently and assert something no source said.

Output

Tracked updates

A later revision of the same document supersedes: the old satellite row is end-dated, the new one opens. Nothing is overwritten.

Conflicting information

A different document asserting something else is not an update — both rows stay open and the slot is flagged. Asked about a flagged slot, the system reports the disagreement instead of picking a side.
